** Docker
Định nghĩa: Docker là công cụ giúp đóng gói ứng dụng và toàn bộ phần mềm đi kèm vào một container (thùng chứa) riêng biệt.
Tác dụng: Giúp ứng dụng chạy ổn định trên mọi máy tính (máy cá nhân, máy chủ) mà không sợ lỗi thiếu thư viện hay khác hệ điều hành.
** Github
Định nghĩa: GitHub là nền tảng trực tuyến dùng để lưu trữ, quản lý và chia sẻ mã nguồn (code) dựa trên hệ thống quản lý phiên bản Git.
Tác dụng: Giúp nhiều lập trình viên cùng làm việc trên một dự án, theo dõi lịch sử chỉnh sửa code và sao lưu dữ liệu an toàn.
