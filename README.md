## 🎯 About The Project

**BPURD** is a comprehensive robotics initiative focused on building a highly agile and fully customized quadruped robot dog. From mechanical design and custom printed circuit boards (PCBs) to embedded firmware and complex kinematics, this organization serves as the central hub for the entire development lifecycle.

The core philosophy behind BPURD is to achieve high precision and dynamic locomotion through optimized hardware architecture and efficient control algorithms.

### ✨ Key Technical Highlights
* 🦾 **Mechanical Design:** Utilizing advanced structural designs, including **Parallel Linkage** mechanisms, to ensure leg agility, strength, and lightweight performance.
* ⚡ **Custom Electronics:** Purpose-built PCB schematics and layouts designed for seamless integration, power distribution, and motor control.
* 🧠 **Embedded Systems:** Core processing handled by **STM32** architectures, ensuring real-time responsiveness and stable sensory data processing.
* 📐 **Kinematics & Control:** Custom Python/C++ workspaces for inverse kinematics, gait planning, and trajectory optimization.

| :--- | :--- | :---: |
| 🧮 [**`kine_workspace`**](https://github.com/BPURD-BeniotPhanUltimatRobotDog/kine_workspace) | Inverse/Forward Kinematics calculations and workspace simulations. | 🟢 Active |

| ⚙️ **`bpurd-firmware`** | *[Coming Soon]* Low-level STM32 embedded code, motor drivers, and sensor reading modules. | 🟡 Planned |
| 🎮 **`bpurd-software`** | *[Coming Soon]* High-level control, communication interfaces, and teleoperation dashboards. | 🟡 Planned |

> **Note:** Heavy media files, large 3D renders, research books, and extensive documentation are not stored in these repositories to maintain optimal Git performance. They are securely linked and managed via our external cloud drives within the respective project wikis.
